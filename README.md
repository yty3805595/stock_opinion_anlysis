# 📈 投资分析报告仓库

这个仓库用于保存 OpenClaw Agent Team 生成的自动投资分析报告。

## 🤖 Agent 团队

| Agent | 角色 | 职责 |
|-------|------|------|
| Astra | 财富管理大师 | 投资策略、资产配置 |
| Analyst | 数据分析师 | 市场分析、数据监控 |
| Trader | 量化交易员 | 订单执行、风险管理 |
| Researcher | 研究员 | 深度调研、行业分析 |

## 📁 报告结构

- `reports/daily_YYYY-MM-DD.md` - 每日投资分析报告
- `reports/weekly_YYYY-Www.md` - 每周投资总结
